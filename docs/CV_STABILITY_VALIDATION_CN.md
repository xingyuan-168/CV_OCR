## 实现与兼容性

- x86/x64 工作区数量上限为 2/4；超额调用等待。空闲缓存预算为 64/256 MiB，归还超预算工作区时释放其实际矩阵和容器容量。
- 移除按模板尺寸增长的线程缓存、多模板内部并行、跨调用结果缓存及模板强引用。评分、候选提取、排序、坐标与公开 ABI 不变。
- 明确校验句柄、模式、相似度、偏色、模板列表；拒绝 BMP 高度 INT32_MIN、非法头区和不可表示尺寸。
- 九个 CV 导出增加 C++ 异常边界；错误文本包含不分配内存的线程局部后备存储。访问违规不属于可恢复的 C++ 错误。
- 构建测试钩子仅在 `AIENGINE_CV_TEST_HOOKS=ON` 开启；所有候选包均为 OFF，公开导出仍为 60 个。

## 真实性能优化（2026-09-18 至 2026-09-20）

已确认 x64 OpenCV 的 IPPICV 下载因连接重置失败，原依赖脚本继续构建，导致安装产物没有 `HAVE_IPP`。本次重新下载并验证上游固定包哈希，重建启用 IPP 的 x64 SDK；依赖准备增加下载 SHA-256、配置宏和静态库检查，正反测试覆盖缺少头文件、缺少宏、相似但错误的宏名、缺少库和空库。

彩色小图路径共享本帧的三通道频谱、积分与平方和，复用一个 DFT 计划及工作缓冲；模板自身最多保留一套当前图像尺寸的频谱。工作区没有模板强引用，也没有上一帧结果。超过内部面积范围的图像、灰度及实际透明掩码路径保留 OpenCV 实现。SIMD 独立编译并运行时检测，兼容路径保留。所有新增工作区矩阵和 DFT 计划/缓冲计入空闲预算；模板频谱属于模板资源，随模板快照释放，不属于空闲工作区预算。

快速路径限制为 512K 像素，因此每通道积分最大值为 133693440，使用精确 int32 积分减少内存带宽；平方和与归一化保留 double。只有输入逐字节相同才复用图像频谱/统计，图像变化会使其失效。每次调用仍执行模板相关、候选提取、精确校验和结果格式化。单目标预处理与多目标所需通道积分有效性分别跟踪。

候选提取在稀疏阈值区域直接检查同一个矩形最大值判定，密集时保留膨胀算法。低于候选阈值的归一化采用保守余量跳过除法；保留彩色精确验证，未截断候选数量。数值测试比较完整评分矩阵，覆盖不整齐尺寸、单像素和常量模板、SIMD 及兼容分支。

变化图像测试使用 610×318 BMP 和现有两个约 30×25 模板；64 组帧覆盖背景/位置移动、未命中及精确得分附近的阈值，先与 OpenCV 参考路径逐项比较完整文本结果，再预热并执行普通/透明各至少 1000 次。参考模式仅在测试 DLL 中可用。发布 DLL 不包含测试钩子。

本机为 Intel Core i7-13620H，Windows 平衡电源方案。优化过程中记录过固定性能核诊断，最终 CTest 和变化图像验收均使用默认调度，不修改亲和性、优先级或电源方案；性能采样与编译/长压测错开。P95 不是最大延迟承诺，也不代表所有尺寸或部署硬件。
